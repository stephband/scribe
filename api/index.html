Sequence Documents & Musical Structure

Scribe consumes Sequence data. The only strictly required property is an "events" array. By convention, Scribe treats the top-level sequence as describing the overarching formal structure of the composition.

Child "sequence" events placed in the top-level array cue movements, sections, or phrases defined in the "sequences" array. Scribe automatically renders double bar lines at the end of each cued section: 

{
    "name": "So What",
    "author": { "name": "Miles Davis" },
    "events": [
        [0,  "key", "C"],
        [0,  "meter", 4, 1],
        [0,  "sequence", 1, 0, 32],
        [32, "sequence", 1, 0, 32],
        [64, "sequence", 1, 0, 32, "transpose", 1],
        [96, "sequence", 1, 0, 32]
    ],

    "sequences": [{
        "id": 1,
        "name": "Section",
        "events": [
            [0,  "sequence", 2, 0, 8],
            [8,  "sequence", 2, 0, 8],
            [16, "sequence", 2, 0, 8],
            [24, "sequence", 2, 0, 8]
        ]
    }, {
        "id": 2,
        "name": "Horns",
        "events": [
            [0,   "chord", "D", "-7", 8],
            [2,   "note", "B4", 0.1, 1.6],
            [2,   "note", "G4", 0.1, 1.6],
            [2,   "note", "D4", 0.1, 1.6],
            [2,   "note", "A3", 0.1, 1.6],
            [3.6, "note", "A4", 0.1, 0.4],
            [3.6, "note", "F4", 0.1, 0.4],
            [3.6, "note", "C4", 0.1, 0.4],
            [3.6, "note", "G3", 0.1, 0.4]
        ]
    }]
}

Automatic Bar Repeat Detection

Rather than writing out verbatim identical measures, Scribe detects repeated bar patterns across sequences and automatically replaces them with standard bar repeat symbols.

Repeat replacement rules:

  • 1-bar repeats: Activated after 3 repetitions ("AAAA" renders as "x %1 %1 %1").
  • 2-bar repeats: Activated after 2 repetitions of a 2-bar figure ("ABABAB" renders as "x x - %2 - %2").
  • 4-bar repeats: Activated after 1 repetition of a 4-bar section ("ABCDABCD" renders as "x x x x - - %4 -").
  • Structural protection: Repeats never cross double bar lines (the first bar of a new section is always fully engraved), and bars with incoming tied notes are protected from repeat substitution.

Sequence Shorthand ("text/sequence")

For rapid authoring in HTML documents, Scribe parses a whitespace-delimited shorthand format embedded inside <script type="text/sequence"> elements: 

<script type="text/sequence" id="tune">
    0 key D
    0 meter 4/4
    0 D4 1
    1 F#4 1
    2 A4 1
</script>
<scribe-music src="#tune"></scribe-music>

Shorthand type inference:

  • Bare note names: Tokens like D4, F#4, or Bb3 automatically resolve as note events without the "note" keyword.
  • Chord symbols: Standard chord notation (e.g. Cmaj7, D-7, G7alt) is inferred directly without requiring explicit "chord" keywords.
  • Whitespace delineation: Each event line follows [beat] [token] [duration] or keyword declarations like 0 key D and 0 meter 4/4.

Programmatic DOM & JavaScript API

The <scribe-music> element reflects all attributes as live JavaScript DOM properties. Querying and mutating these properties triggers an immediate, reactive re-render:

property attribute type description
.src src URL | string URL of sequence file or selector to an inline script (e.g. "#tune")
.type type string Mimetype: "application/json" (or "json"), "text/sequence"
.staff staff string Clef/stave configuration (defaults to "treble")
.key key string Tonic of major key signature (e.g. "C", "F#", "B♭")
.meter meter string Time signature (e.g. "4/4", "3/4", "6/8")
.beat beat number Starting beat from which notation rendering begins (defaults to 0)
.duration duration number Total duration in beats to render (defaults to Infinity)
.transpose transpose number Pitch and key transposition offset in semitones
.swing swing boolean Boolean flag; displays swung 8ths as straight 8ths
.shuffle shuffle boolean Boolean flag; displays swung 16ths as straight 16ths
.data — object Reactive sequence data object; mutating this immediately triggers a re-render

JavaScript DOM Manipulation

Attributes and properties can be manipulated imperatively via standard DOM methods or direct property assignment: 

// Query the music element
const scribe = document.querySelector('scribe-music');

// Inspect reflected properties
console.log(scribe.staff);      // "treble"
console.log(scribe.key);        // "C"

// Programmatically update properties (triggers dynamic re-render)
scribe.key = "B♭";
scribe.meter = "3/4";
scribe.transpose = 2;
scribe.staff = "bass";

// Push events into the reactive data structure
scribe.data.events.push([12, "note", "C4", 0.1, 1]);

Key Signatures, Transposition & Clefs

The Relative Major Rule

Scribe has no provision for declaring minor key signatures directly (e.g. setting key="Dm" is not supported). Always declare the relative major tonic (e.g. use key="F" for D minor, or key="Eb" for C minor).

Key names accept both Unicode accidentals ("♯", "♭") and ASCII symbols ("#", "b").

Key Signature Transposition

The key attribute sets the pre-transposition key signature. When transpose is specified (e.g. transpose="2"), the key signature is automatically transposed alongside all notes and chord symbols before engraving.

Supported Staves and Clefs

The staff attribute accepts standard clefs as well as octave-transposing clefs:

  • "treble" (default): Standard G-clef on second line.
  • "treble-up": Treble clef 8va (sounds one octave higher than written).
  • "treble-down": Treble clef 8vb (tenor vocal clef, sounds one octave lower than written).
  • "alto": C-clef on third line.
  • "tenor": C-clef on fourth line.
  • "bass": Standard F-clef on fourth line.
  • "grand": Braced piano stave combining treble and bass staves.
  • "drum" / "percussion": Neutral percussion clef with unpitched drum kit mappings.

Render Process

Scribe serialises a sequence into a transferable stride-8 Float64Array, renders, spells, and hashes bars inside a Web Worker, and returns only the changed HTML bars to patch the shadow DOM.

1

Flatten & Serialise Sequence to Stride-8 Float64Array

serialise(iterator)

Expand the sequence via SequenceIterator(..., { outputInBeats: true }) and pack renderable events (note, chord, meter, key, text, clef) into a stride-8 Float64Array, skipping sequence, rate, and control events. Assign and store event IDs via identify(original(event)), preserve target and voice, and store strings from text events in a companion texts[] lookup array.

[+0]beat
[+1]type
[+2]pitch / rsid / key / dur
[+3]gain / hsid / div / textIdx
[+4]duration
[+5]target (-1)
[+6]voice (-1)
[+7]id (0+)
2

Call renderHTMLOnWorker() & Transfer Buffer

compile-worker.js

Normalise parts with part.toJSON() and hand ownership of [data.buffer] to the Web Worker via zero-copy transferable postMessage() alongside texts, existing bar hashes[], key, timesig, beat, settings, and debug.

Main → Worker postMessage { data: Float64Array, texts, hashes, parts, key, timesig, beat, settings } Transfer: [data.buffer]
Web Worker — Quantise, Spell, Symbolise, Render & Hash
modules/render/worker.js (bundled → worker-code.js)
3

Deserialise data into Event Objects

render/deserialise.js

Unpack each stride-8 record and texts[index] back into NoteEvent, ChordEvent, MeterEvent, KeyEvent, and TextEvent objects, restoring event.id, event.target, and event.voice.

4

Create Tree & Analyse Metric Quantisation

tree/read.js → tree/quantise.js

read() groups events into bars along meter boundaries, routes events to parts and voices in part.buffers[voiceName], and collects spellables. Then quantise() runs the Elastic Phase-Locked Metrical Quantiser (EPL-MQ) across every bar, part, and voice.

4.1 Quantisation Steps · quantise.js + rhythm.js Per bar × part × voice
4.1.1
Carry PLL Drift
Track expressive performer drift in drifts[part.voice]; reset to 0 if a bar buffer is empty.
4.1.2
Phasor Divisor Fit
detectRhythmPrime() scores primes = [9,7,5,3,2] ([3,2] for chords) via cos/sin(x·2π) in frame t − drift.
4.1.3 ◊ Split?
Binary-Tree Bifurcation
detectBestFit() compares coarse fit afit vs splitting [beat, d/2) + [+d/2, d); split if bfit > afit + 1e-4.
4.1.4
Swing Straightening
straighten() flattens triplet swing/shuffle bitmaps (divisor 3, rhythm 4|5) to divisor 2 when configured.
4.1.5
Quantise & Evolve
quantiseTupletEvents() snaps event[0] & event.slot, attaches voice.tuplets, and passes driftOut forward.
5

Spell Notes, Chords & Keys

modules/spell.js + neuron

Spell notes, chords, and keys by part, or across the whole document simultaneously when settings.showAtConcertPitch is enabled.

◊ settings.showAtConcertPitch? true: run spell(tree.spellables) document-wide · false: transpose & spell per part in Promise.all(tree.parts.map(spellPart))
5.1–5.4 Spelling Steps · spell/batch.js → analyse.js → schema.js → network-cpu.js
5.1
Group Time Slices
batch(events) groups concurrent events into timed slices with local beat, grain, and base key.
5.2
Analyse Key Fit
analyseKeys() deterministically scores slices against circle-of-fifths key profiles.
5.3 BiGRU
RNN Key Inference
encode() passes circle-of-fifths pitches, key scores, beat, duration, Δt, home key, and grain into rnn.predict().
5.4
Spell from Key
decode() sets chosen event.key on notes and chords for deterministic enharmonic spelling.
6

Create Per-Bar, Per-Part, Per-Voice Symbol Lists

tree/symbolise.js + bar-repeater.js

Transform quantised tuplets and sustained notes into symbol descriptors per bar, part, and voice, replace repeated bars with repeat signs, and prune empty trailing bars.

6.1 Symbolisation Steps · symbolise.js + bar-repeater.js + stave/*
6.1.1
Reset Beams & Bar Signatures
Call resetBeamId() per bar for deterministic HTML; resolve transposed part.key and prepend key acci + timesig symbols.
6.1.2
Chords, Lyrics & Tied Voices
symboliseChords() / symboliseText() clip symbols at barlines; restore activeNotes tied over from the previous bar per voice.
6.1.3 ◊ Tuplet?
Tuplet Slots vs Duplet Flow
isTupletSymbol() true: emit tuplet bracket and walk slots 0..divisor-1. False: group chord clusters at beat and call fillToBeat().
6.1.4
Beams, Rests & Accidentals
createNoteSymbols / createDupletNoteSymbols emit heads, accidentals, ties, accents, ledges; updateBeamWithNoteSymbols() beams across divisions; empty bars get whole rests.
6.1.5
Bar-Repeat Detection
BarRepeater.push() hashes bar content (resetting on doubleBarLine) and replaces 1-, 2-, or 4-bar runs with barrepeat glyphs.
6.1.6
Prune Phantom Overhang
Drop trailing empty overhang bars not marked endOfSequence (hasBarContent()), then flag doubleBarLine = true on the final bar.
7

Render Per-Bar HTML & Generate 53-bit Hash

create-html.js + tree/hasher.js

Serialise each bar via createBarHTML(bar) (reading event.id directly onto DOM attributes) and compute a 53-bit cyrb53 fingerprint via hashString(html).

8

Diff Against Incoming hashes[]

render/worker.js

Filter out bars whose hash equals hashes[index]; keep only new or changed bars as { index, beat, html, hash }.

9

Create Single Signature Set

createSigHTML(tree[0])

Build one <music-sig> HTML string for the staves and wrap it as { beat: 0, html, hash } inside signatures[].

10

Return { signatures, bars, length }

self.postMessage()

Post the diffed payload back to renderHTMLOnWorker() on the main thread (guarding against out-of-order async responses with frameId).

Worker → Main postMessage { signatures: [{ beat: 0, html, hash }], bars: [{ index, beat, html, hash }], length }
Main Thread — Patch Shadow DOM
scribe-music/element.js → patchShadow() & toHeaderHTML()
11

Replace or Append Each Bar

patchShadow()

Replace changed <music-bar> elements in place via outerHTML or append new bars via insertAdjacentHTML('afterend', html), prune trailing bars if barEls.length > length, and update hashes[index].

12

Generate Signatures & Prepend

toHeaderHTML()

When sigHash !== internals.sigHash, repeat signatures[0].html 24 times to fill vertical space inside <header id="side" class="side"> and prepend it before bar 0; CSS Grid + SMuFL fonts lay out the notation natively.

    Data Contracts

    1. Request Payload (Transferable)

    {
  data:     Float64Array, // 8 floats/event (transferred)
  texts:    string[],     // lookup table for text events
  hashes:   number[],     // previous 53-bit bar hashes
  parts:    PartJSON[],   // plain objects via part.toJSON()
  key, timesig, beat, settings, debug
}

    2. Worker Tree Structure

    tree: Array<Bar>
  bar[p]:   Part { stave, key, symbols[], [v]: Voice }
  voice:    { name, staff, tuplets[] }
  symbol:   { type, beat, duration, pitch, event, ... }
  repeat:   { type: 'barrepeat', count: 1|2|4 }

    3. Response Diff Payload

    {
  signatures: [{ beat: 0, html, hash }],
  bars:       [{ index, beat, html, hash }],
  length:     number, // total bars after pruning
  debug:      { w0, ta, tb, tc, td, t1, t2, w3 }
}

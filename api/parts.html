Multi-Stave Scoring

Scribe decouples instruments ("objects") from the staves they are rendered on ("parts").

Objects and parts

When multiple instruments play concurrently, Scribe stacks their staves synchronously within each flex measure. In So What, five separate voices (Trumpet, Alto sax, Tenor sax, Trombone, and Bass) are declared in the sequence data. Here are the opening four bars: 

<scribe-music src="../data/so-what.json" duration="16"></scribe-music>

1. Declaring Sound Sources: "objects"

The top-level sequence declares an "objects" array. Each object assigns an identifier and human-readable instrument name: 

{
    "name": "So What",
    "objects": [
        { "id": 2, "name": "Trumpet" },
        { "id": 3, "name": "Alto sax" },
        { "id": 4, "name": "Tenor sax" },
        { "id": 5, "name": "Trombone" },
        { "id": 6, "name": "Bass" }
    ],
    "events": [ ... ]
}

Sequence events route musical material into these objects using their id in the fourth parameter of a "sequence" event: [beat, "sequence", sequenceId, targetObjectId, duration]. 

[
    [0, "sequence", 2, 2, 8], // routes sequence 2 to object 2 (Trumpet)
    [0, "sequence", 3, 3, 8], // routes sequence 3 to object 3 (Alto sax)
    [0, "sequence", 4, 4, 8], // routes sequence 4 to object 4 (Tenor sax)
    [0, "sequence", 5, 5, 8], // routes sequence 5 to object 5 (Trombone)
    [0, "sequence", 6, 6, 4]  // routes sequence 6 to object 6 (Bass)
]

2. Automatic Stave Resolution

When no explicit "parts" definition is supplied, Scribe inspects each object's name and applies sensible instrument defaults: Trumpet, Alto, and Tenor resolve to treble staves; Trombone and Bass resolve to bass staves.

Grand Stave & Voice Routing: "Ae Fond Kiss"

For keyboard or polyphonic instruments, multiple independent musical lines frequently funnel into a single grand stave. The "parts" array configures how objects map into stave hands and voices. 

<scribe-music staff="grand" src="../data/ae-fond-kiss.json" duration="12"></scribe-music>

In Robert Burns' traditional air Ae Fond Kiss, the melody (object 2) is explicitly directed to the right hand ("rh") while the accompaniment (object 1) is directed to the left hand ("lh"): 

{
    "name": "Ae Fond Kiss",
    "objects": [
        { "id": 1, "name": "Accompaniment" },
        { "id": 2, "name": "Melody" }
    ],
    "parts": [{
        "staff": "grand",
        "name": "Piano",
        "voices": {
            "rh": 2,
            "lh": 1
        }
    }]
}

Parts

property type description
staff string Stave type: "grand", "treble", "treble-up", "treble-down", "alto", "tenor", "bass", "drum", "percussion"
name string Part name used for labelling, system matching, and fallback display resolution
clef string Optional clef override if different from the default stave clef
transpose number Per-part transposition in semitones
voices object Dictionary mapping voice destinations to source object IDs

Voice Targets in Grand Staves

When targeting a "grand" stave, the keys of the "voices" object determine how lines are routed across staves and stem directions:

voice key voice name stave / behavior
"0" Auto-split Automatically splits notes across treble and bass staves based on pitch (middle C threshold)
"1" or "rh" Right hand Treble stave, upward/standard stem distribution
"2" or "lh" Left hand Bass stave, downward/standard stem distribution
"3" Soprano Upper voice on treble stave (stems up)
"4" Alto Lower voice on treble stave (stems down)
"5" Tenor Upper voice on bass stave (stems up)
"6" Bass Lower voice on bass stave (stems down)
